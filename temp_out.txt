## ROOT CAUSE #1 — The chunker only recognizes U-codes (this is the big one)

This is why 5 codes are missing from "list all" and why counts are off even after re-ingest.

**File:** `ai-service/src/services/strategic_chunker.py`

The coverage row regex only matches lines starting with `U`:

```python
COVERAGE_ROW_RE = re.compile(
    r"^U\d{3,4}\s*\|",
    re.MULTILINE | re.IGNORECASE,
)
```

This means **D0001, D0002, D0003, D0005, ET460, E6460, G30, HAC49, TOW1, TOW2, TOW4, Z0421, Z0423** are all treated as prose instead of coverage table rows. They don't get `chunkType="coverage_table"`, they don't get `coverageCodes` populated, and the aggregation engine's `row_chunks` counter misses them.

**Fix — replace `COVERAGE_ROW_RE`:**

```python
COVERAGE_ROW_RE = re.compile(
    r"^(?:U\d{3,4}[A-Z]?|D\d{4}|ET\d{3}|E\d{3,4}|G\d{2,3}|HAC\d{2,3}|TOW\d+|Z\d{3,4})\s*[\|]",
    re.MULTILINE | re.IGNORECASE,
)
```

**Also fix `_extract_u_codes`** (same file, around line 530) — it only pulls U-codes:

```python
def _extract_u_codes(text: str) -> list[str]:
    return sorted(set(re.findall(r"\bU\d{3,4}\b", text, flags=re.IGNORECASE)))
```

Replace with a function that catches all code types:

```python
def _extract_u_codes(text: str) -> list[str]:
    """Extract all warranty coverage codes (U, D, ET, E, G, HAC, TOW, Z)."""
    patterns = [
        r"\bU\d{3,4}[A-Z]?\b",
        r"\bD\d{4}\b",
        r"\bET\d{3}\b",
        r"\bE\d{3,4}\b",
        r"\bG\d{2,3}\b",
        r"\bHAC\d{2,3}\b",
        r"\bTOW\d+\b",
        r"\bZ\d{3,4}\b",
    ]
    codes: set[str] = set()
    for pat in patterns:
        codes.update(re.findall(pat, text, flags=re.IGNORECASE))
    return sorted(codes, key=str.upper)
```
